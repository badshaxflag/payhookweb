key বসান। অ্যাপ খুলে ওপরের key বসান, তারপর SMS-এর অনুমতি দিন।
সেটআপ ফাইল বানান। নিচের ফর্ম পূরণ করলে আপনার বট বা ওয়েবসাইটের জন্য তৈরি ফাইল পাবেন। কোড বোঝা বা বদলানোর দরকার নেই।
অ্যাপ ডাউনলোড করুন ডাউনলোডের লিংক শীঘ্রই এখানে যোগ হবে।

আপনার সেটআপ ফাইল বানান

নিচের তথ্য দিন। আপনার জন্য সব বসানো একটা ফাইল নামবে। তথ্যগুলো শুধু আপনার ফোনের ব্রাউজারে ব্যবহার হয়, আমাদের সার্ভারে পাঠানো হয় না।

@BotFather-এ বট বানালে যে টোকেন দেয় সেটা। এটা গোপন জিনিস, তাই শুধু আপনার ফাইলে বসবে। আইডি জানতে টেলিগ্রামে @userinfobot-কে /start লিখুন।

সতর্কতা: ফাইলে আপনার key (আর বটের টোকেন) বসানো থাকবে। ফাইলটা কাউকে দেবেন না, GitHub বা কোনো পাবলিক জায়গায় তুলবেন না।

নিজে কোড লিখতে চাইলে (ডেভেলপারের জন্য)

আপনার সাইটে ক্রেতা টাকা পাঠিয়ে TrxID লিখে দিলে, আপনার সাইট আমাদের সার্ভারকে জিজ্ঞেস করবে "এই টাকা এসেছে?" সার্ভার সাথে সাথে উত্তর দেবে। নিচের ধাপগুলো একটা একটা করে করুন।

ধাপ ১: তৈরি রাখুন

তিনটা জিনিস লাগবে: (ক) ওপরের আপনার key, (খ) আপনার সাইটের ডোমেইন, যেমন myshop.com (বটের ক্ষেত্রে বটের নাম), (গ) ইন্টারনেটসহ চালু ফোনে PayHook অ্যাপ।

ধাপ ২: ক্রেতাকে বলুন কী করতে হবে

আপনার চেকআউট পেজে নিজের bKash, Nagad বা Rocket নম্বর আর ঠিক কত টাকা পাঠাতে হবে লিখে রাখুন। তার নিচে ক্রেতার জন্য দুটো ঘর রাখুন: কোন মাধ্যমে পাঠিয়েছে (তালিকা থেকে বাছার ঘর) আর TrxID লেখার ঘর।

ধাপ ৩: যাচাইয়ের কোড বসান

ক্রেতা "জমা দিন" চাপলে আপনার সাইটের সার্ভার এই কোড চালাবে। আপনার সাইট যে ভাষায় বানানো সেটা বেছে নিন, কোডটা কপি করে সেখানে বসান। বেশিরভাগ সাধারণ সাইট (WordPress, cPanel হোস্টিং) PHP-তে চলে।


        
        
কোডে এই জিনিসগুলো বদলাতে হবে: key, সাইটের ডোমেইন, ক্রেতার দেওয়া TrxID ও মাধ্যম, আর ওই অর্ডারের দাম। বাকি সব যেমন আছে তেমন থাকবে।

        
জরুরি: key-টা সাইটের সার্ভারের ফাইলে রাখুন, ব্রাউজারে চলা HTML বা JavaScript পাতায় নয়। নইলে ক্রেতা পাতা খুলে আপনার key দেখে নিতে পারবে। একটা key শুধু একটা ডোমেইনেই চলে, যেখানে প্রথম ব্যবহার হয় সেখানে বাঁধা পড়ে যায়।

        
ধাপ ৪: উত্তর বুঝুন

        
উত্তরে status যদি success আসে, পেমেন্ট ঠিক আছে, ক্রেতাকে পণ্য বা সার্ভিস দিন। success হওয়ামাত্র ওই TrxID "ব্যবহৃত" হয়ে যায়, তাই প্রতিটা অর্ডারে কোডটা একবারই চালান। শুধু দেখে নিতে চাইলে (TrxID ব্যবহৃত না করে) পাঠানো তথ্যের সাথে dry_run নামে একটা ঘরে 1 পাঠান। সফল না হলে reason ঘরে কারণ লেখা থাকে:

        

          
Invalid or expired key.
key ভুল, বন্ধ, বা মেয়াদ শেষ।

          
This key is connected to another place.
key অন্য ডোমেইনে বাঁধা। ডোমেইনের নাম সবসময় একই লিখুন।

          
Transaction not found.
TrxID ভুল, বা SMS এখনো আসেনি। ফোনে অ্যাপ খুলে সিঙ্ক করুন, তারপর আবার চেষ্টা করুন।

          
Payment method does not match.
ক্রেতা এক মাধ্যম বেছে অন্য মাধ্যমের TrxID দিয়েছে।

          
Amount does not match.
টাকা কম বা বেশি পাঠানো হয়েছে।

          
Transaction already used.
এই TrxID আগেই ব্যবহার হয়ে গেছে।

          
Too many invalid attempts.
ভুল key দিয়ে অনেকবার চেষ্টা হয়েছে, কিছুক্ষণ পর আবার করুন।

        

        
ধাপ ৫: পরীক্ষা করে নিন

        
নিজের অন্য একটা নম্বর থেকে ছোট অঙ্ক (যেমন ৳১০) আপনার নম্বরে পাঠান। TrxID নিয়ে dry_run দিয়ে চেষ্টা করুন। success এলে সবকিছু ঠিক আছে, এবার আসল ক্রেতাদের জন্য চালু করুন।

মেয়াদ কবে থেকে ধরা হয়?
